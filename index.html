02 — Infra

Servidor, deploy e automação

Quando o projeto não tem time de infra separado, eu mesmo subo VPS, nginx, docker e o que mais fizer falta.

DevOps & infra

Da VPS ao deploy: Oracle Cloud, Azure e AWS (S3, ECR), serviços com Docker / Compose e bancos MySQL, PostgreSQL, Redis ou MongoDB. Orquestração com GitHub Actions, registry na AWS e Coolify self-hosted quando faz sentido para o time.
